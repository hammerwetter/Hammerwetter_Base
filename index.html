HomeAssistant (private Anwendung)

Diese Anwendung wird ausschließlich privat genutzt, damit meine Home-Assistant-Installation auf meine eigenen Google-Kalender zugreifen kann.

Datenschutz

Kalenderdaten werden nur lokal in Home Assistant verarbeitet. Es werden keine Daten an Dritte weitergegeben, verkauft oder für andere Zwecke verwendet.
